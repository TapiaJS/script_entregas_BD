# Script de Automatización de Entregas - Fundamentos de Bases de Datos
**Equipo:** Hotline

Este script automatiza la creación de la estructura de directorios y el empaquetado final de las tareas, prácticas y el proyecto final de la asignatura. 

Garantiza el cumplimiento estricto de los lineamientos de entrega, evitando penalizaciones por errores tipográficos en los nombres de carpetas o archivos.

## Requisitos previos:
1. Python 3 instalado en el sistema (Ubuntu).
2. Los archivos a entregar deben estar en el mismo directorio que este script.
3. El archivo README debe llamarse exactamente `README_Hotline.pdf`.
4. El archivo del documento principal debe llamarse `TipoNN.pdf` (ej. `Practica02.pdf`).

## Uso:
Ejecutar el script desde la terminal: 
```bash
python3 entregas.py
